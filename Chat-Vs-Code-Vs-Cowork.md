# Claude Chat vs Claude Code vs Claude Cowork
**Video script — target runtime: ~4 minutes**

---

## [SCENE 1 — INTRO] (0:00–0:20)

Anthropic makes one AI — Claude. But depending on what you're trying to get done, you don't always want to work with it the same way.

There's Claude Chat. There's Claude Code. And there's Claude Cowork.

They all run on the same underlying model. What changes is how much access Claude has, and how much you have to steer it. Let's break down the differences — and when to reach for each one.

---

## [SCENE 2 — CLAUDE CHAT] (0:20–1:10)

First up: Claude Chat. This is the classic conversation. You type a message, Claude replies, back and forth.

Chat is built for thinking things through — drafting an email, brainstorming ideas, getting a second opinion on a plan, learning a new concept, or asking a quick question. You can upload a file or paste in some text and Claude will read it and respond.

But here's the key limit: in a regular chat, Claude responds to what you send it. It doesn't reach into your computer, open your folders, or go off and complete a multi-step task on its own. If you want it to act on your files directly, you have to paste content in and copy results back out.

Think of Chat as your thinking partner — fast, conversational, and great for anything that lives inside a single exchange.

---

## [SCENE 3 — CLAUDE CODE] (1:10–2:20)

Next: Claude Code. This one is built specifically for software engineering — writing, debugging, and shipping real code.

You use it from the terminal, inside the Claude desktop app, or right inside your IDE — tools like VS Code and JetBrains. Claude Code can read your actual codebase, make edits across multiple files, run your tests, fix errors it finds, and commit changes — all while you review and steer along the way.

It's built for developers who live in a code editor and want an agent that understands their repo, not just a snippet you copy and paste. If your task is "build this feature," "fix this bug," or "refactor this module," Claude Code is the tool built for exactly that job.

---

## [SCENE 4 — CLAUDE COWORK] (2:20–3:30)

Then there's Claude Cowork — think of it as the same agentic power as Claude Code, but built for everyone else's work, not just code.

Cowork is for non-coding knowledge work: research, analysis, document creation, and other multi-step tasks. You give Claude access to specific files and folders, describe the outcome you want, and Claude plans the work, breaks it into steps, and executes it — reading, editing, and creating files along the way, instead of just describing how you'd do it yourself.

You can start a task at your desk, check on it from your phone, and come back to a finished deck, document, or spreadsheet. You can even schedule tasks to run on a daily, weekly, or monthly cadence, and Cowork keeps working even after you close your laptop. At every step, Claude shows you what it's doing — which files it opened, which tools it used — so you can follow along and redirect it if needed.

If Claude Code is an agent for your codebase, Cowork is an agent for your desk.

---

## [SCENE 5 — SIDE-BY-SIDE RECAP] (3:30–4:00)

So, quick recap:

Claude Chat — a conversation. Best for thinking, drafting, and quick answers.

Claude Code — an agent for developers. Best for writing, debugging, and shipping code inside your IDE or terminal.

Claude Cowork — an agent for everyone else. Best for multi-step work across your files, folders, and apps — research, documents, spreadsheets, and more.

Same Claude underneath. Different level of access, different level of autonomy — so you can pick the right mode for the work in front of you.

## [SCENE 6 — OUTRO] (4:00–4:10)

That's Claude Chat, Claude Code, and Claude Cowork — three ways to work with the same AI, built for three different kinds of work.
